# Online Voting System 🗳️

A web-based Online Voting System developed as a **20-day academic task** for **MIT (1st Semester)** to simulate a real-world digital voting process.

---

## 📌 Project Overview

This project provides a complete voting workflow including voter login, candidate listing, vote casting, admin management, and live vote statistics.  
All data is handled on the client side using **localStorage** for demonstration and academic purposes.

---

## 🛠️ Features

- Voter login with validation
- Admin dashboard to manage candidates and voters
- Secure vote casting (one vote per session)
- Real-time vote count updates
- Live graphical representation of votes using Chart.js
- Responsive UI for desktop, tablet, and mobile
- Automatic winner highlighting based on vote count
